Formulario y glosario

Todas las fórmulas de la materia, unidad por unidad, y los términos clave. Convención de la cátedra: tasas anuales con composición continua y año de 360 días (30/360), salvo que se indique otra cosa.

No hay fórmulas ni términos que coincidan con la búsqueda.

Unidad I · Forwards y futuros

Resultado de un forward al vencimiento

\[ \text{Largo: } S_T - K \qquad \text{Corto: } K - S_T \]

Ajuste diario de una posición en futuros

\[ \text{Ganancia del día} = (F_t - F_{t-1}) \times \text{tamaño del contrato} \times \text{contratos} \quad (\text{posición larga}) \]

Si el saldo de la cuenta cae por debajo del margen de mantenimiento, hay llamado de margen: se repone hasta el margen inicial.

Unidad II · Cobertura con futuros

Base y precio efectivo

\[ b_t = S_t - F_t \qquad \text{Precio efectivo} = F_1 + b_2 = S_2 + (F_1 - F_2) \]

Ratio de cobertura de mínima varianza

\[ h^* = \rho\,\frac{\sigma_S}{\sigma_F} \qquad N^* = \frac{h^* Q_A}{Q_F} \qquad \text{efectividad} = \rho^2 \]

Tailing the hedge (ajuste por valor)

\[ N^* = \frac{h^* V_A}{V_F} \]

Cobertura con futuros sobre índices

\[ N^* = \beta\,\frac{V_A}{V_F} \qquad \text{Cambiar la beta de } \beta \text{ a } \beta^*: \; N = (\beta^* - \beta)\,\frac{V_A}{V_F} \]

\(V_F\) = precio del futuro × multiplicador. Si \(N > 0\) se compran futuros; si \(N < 0\), se venden.

Unidad III · Tasas y precios forward

Conversión de tasas

\[ R_c = m \ln\!\left(1 + \frac{R_m}{m}\right) \qquad R_m = m\left(e^{R_c/m} - 1\right) \]
\[ \text{TNA}_{n} \to \text{efectiva a } d \text{ días: } \left(1 + \text{TNA}_n \tfrac{n}{360}\right)^{d/n} - 1 \]

Tasa forward

\[ R_F = \frac{R_2 T_2 - R_1 T_1}{T_2 - T_1} = R_2 + (R_2 - R_1)\,\frac{T_1}{T_2 - T_1} \]

Bonos: precio y duración

\[ B = \sum_i c_i\,e^{-r_i t_i} \qquad D = \frac{\sum_i t_i\,c_i\,e^{-y t_i}}{B} \qquad \Delta B \approx -B\,D\,\Delta y \]

FRA

\[ \text{Flujo del largo en } T_2: \; L\,(R_M - R_K)\,\tau \qquad \text{Liquidación en } T_1: \; \frac{L\,(R_M - R_K)\,\tau}{1 + R_M\,\tau} \]
\[ V_{FRA} = L\,(R_K - R_F)\,\tau\,e^{-R_2 T_2} \quad (\text{para quien recibe } R_K) \]

Precio forward

\[ F_0 = S_0 e^{rT} \qquad F_0 = (S_0 - I)\,e^{rT} \qquad F_0 = S_0 e^{(r - q)T} \]
\[ \text{Monedas: } F_0 = S_0 e^{(r - r_f)T} \qquad \text{Commodities: } F_0 = (S_0 + U)\,e^{rT} \;\; \text{o} \;\; F_0 \le S_0 e^{(r + u - y)T} \]

Valor de un forward ya pactado

\[ f = (F_0 - K)\,e^{-rT} \quad (\text{largo}) \]

Unidad IV · Swaps

Ventaja comparativa

\[ \text{Ganancia total} = \left|\,\Delta_{\text{fija}} - \Delta_{\text{variable}}\,\right| \]

Valuación de un swap de tasa

\[ V_{\text{recibe fija}} = B_{fix} - B_{fl} \qquad B_{fix} = \sum_i k\,e^{-r_i t_i} + L\,e^{-r_n t_n} \qquad B_{fl} = (L + k^*)\,e^{-r_1 t_1} \]

Tasa swap (valor cero al inicio)

\[ R_{swap} = \frac{1 - e^{-r_n T_n}}{\tau \sum_{i} e^{-r_i t_i}} \]

Swap de monedas

\[ V_{\text{recibe doméstica}} = B_D - S_0\,B_F \qquad F_t = S_0\,e^{(r - r_f)t} \]

Unidad V · Opciones: propiedades

Pagos al vencimiento

\[ \text{Call: } \max(S_T - K;\,0) \qquad \text{Put: } \max(K - S_T;\,0) \qquad \text{Beneficio} = \text{pago} - \text{prima} \]

Límites (sin dividendos)

\[ \max(S_0 - Ke^{-rT};\,0) \le c \le S_0 \qquad \max(Ke^{-rT} - S_0;\,0) \le p \le Ke^{-rT} \]

Con dividendos de valor presente \(D\): reemplazar \(S_0\) por \(S_0 - D\).

Paridad put-call

\[ c + Ke^{-rT} = p + S_0 \qquad \text{con dividendos: } c + D + Ke^{-rT} = p + S_0 \]

Banda para americanas

\[ S_0 - K \le C - P \le S_0 - Ke^{-rT} \qquad \text{con dividendos: } S_0 - D - K \le C - P \le S_0 - Ke^{-rT} \]

Unidad VI · Valuación de opciones

Binomial de un paso

\[ \Delta = \frac{f_u - f_d}{S_0u - S_0d} \qquad p = \frac{e^{r\Delta t} - d}{u - d} \qquad f = e^{-r\Delta t}\left[p\,f_u + (1 - p)\,f_d\right] \]

Árbol de Cox-Ross-Rubinstein

\[ u = e^{\sigma\sqrt{\Delta t}} \qquad d = \frac{1}{u} \qquad \text{con rendimiento } q: \; p = \frac{e^{(r - q)\Delta t} - d}{u - d} \]

Propiedad lognormal

\[ \ln S_T \sim N\!\left[\ln S_0 + \left(\mu - \tfrac{\sigma^2}{2}\right)T;\; \sigma^2 T\right] \qquad E(S_T) = S_0e^{\mu T} \]
\[ P(S_T > K) = N(d_2) \text{ calculado con } \mu \text{ en lugar de } r \]

Volatilidad histórica

\[ u_i = \ln\frac{S_i}{S_{i-1}} \qquad \hat\sigma = \frac{s}{\sqrt{\tau}} \qquad \text{error estándar} \approx \frac{\hat\sigma}{\sqrt{2n}} \]

Black-Scholes-Merton

\[ c = S_0N(d_1) - Ke^{-rT}N(d_2) \qquad p = Ke^{-rT}N(-d_2) - S_0N(-d_1) \]
\[ d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)\,T}{\sigma\sqrt T} \qquad d_2 = d_1 - \sigma\sqrt T \]

Griegas (sin dividendos)

\[ \Delta_c = N(d_1) \quad \Delta_p = N(d_1) - 1 \quad \Gamma = \frac{N'(d_1)}{S_0\sigma\sqrt T} \quad \mathcal V = S_0\sqrt T\,N'(d_1) \]
\[ \Theta_c = -\frac{S_0N'(d_1)\sigma}{2\sqrt T} - rKe^{-rT}N(d_2) \qquad \Theta_p = -\frac{S_0N'(d_1)\sigma}{2\sqrt T} + rKe^{-rT}N(-d_2) \]

Unidad VII · Índices, monedas y futuros

Regla de Merton (activo que rinde q)

\[ c = S_0e^{-qT}N(d_1) - Ke^{-rT}N(d_2) \qquad d_1 = \frac{\ln(S_0/K) + (r - q + \sigma^2/2)\,T}{\sigma\sqrt T} \]
\[ c + Ke^{-rT} = p + S_0e^{-qT} \qquad c \ge S_0e^{-qT} - Ke^{-rT} \]

Índice: \(q\) = rendimiento por dividendos. Moneda (Garman-Kohlhagen): \(q = r_f\). Futuro (Black): \(S_0 = F_0\) y \(q = r\).

Modelo de Black (opciones sobre futuros)

\[ c = e^{-rT}\left[F_0N(d_1) - KN(d_2)\right] \qquad p = e^{-rT}\left[KN(-d_2) - F_0N(-d_1)\right] \qquad d_1 = \frac{\ln(F_0/K) + \sigma^2T/2}{\sigma\sqrt T} \]
\[ c + Ke^{-rT} = p + F_0e^{-rT} \qquad \text{árbol: } p = \frac{1 - d}{u - d} \]

Seguro de cartera con puts sobre índice

\[ N = \beta\,\frac{V_0}{m\,S_0} \qquad V_T = V_0\left[1 + rT + \beta\left(\frac{S_T}{S_0} - 1 + qT - rT\right) - qT\right] \]

El strike es el nivel del índice que hace \(V_T\) igual al valor asegurado.
